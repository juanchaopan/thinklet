# thinklet 项目简介

## 目标

thinklet 是面向孩子的做题平台。它用有趣、引人入胜的方式，带孩子学习难懂、复杂的课程，教他们解题，帮他们整理思路。

平台是通用的题库平台：科目和题型不设限，可以扩展。每种题型有自己的教学方式。

## 用户

- **家长**：开放注册，谁都可以用。家长在自己的账号下为每个孩子建档案，给孩子分派书本，查看孩子的学习进度。
- **孩子**：3–18 岁，从学前到高中。孩子没有独立账号，用家长建的档案学习、做题。
- 暂时没有其他角色。内容由平台团队制作和维护。

## 范围

已确定的功能：

- **书架和书本**：内容按书本组织，放在书架上。一本书里有若干教学和对应的练习。
- **家长分派书本**：家长从公共书架挑书，分派给某个孩子。
- **教学和练习分开**：一次教学讲完后，孩子可以做多个相关的练习。
- **题型可扩展**：每种题型是独立的模块，有自己的作答方式和教学方式；加新题型不需要改平台本身。
- **家长查看学习进度**：家长能看到每个孩子的学习情况。
- **内容来源**：题目、教学和书本只由平台团队制作。

暂不在范围内：

- 开放作者投稿、家长自己出题
- 孩子自己注册
- 老师和班级、平台管理员、内容编辑等其他角色
- 分步引导和提示、趣味激励（积分、徽章等）、错题本
- 微信小程序、原生 App

## 客户端

- 网页，一套自适应页面，在手机、平板、电脑的浏览器里使用。
- 手机和平板用触屏操作，电脑用键盘和鼠标。

## 合规

- 用户以中国大陆为主，服务器放在中国大陆，网站需要 ICP 备案。
- 遵守《个人信息保护法》和《儿童个人信息网络保护规定》：孩子的档案由家长建立，处理孩子的个人信息需要家长同意。
