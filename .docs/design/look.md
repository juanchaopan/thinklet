# 视觉和动效

界面的整体感觉：暖色的米白底、白色圆角卡片、深藏青的胶囊按钮，干净、留白多。家长用的页面以小图标点缀，不放卡通人物；小兔老师只出现在产品主页、首页的欢迎横幅和孩子会看到的页面上。

## 颜色

颜色只用 Tailwind 主题里定义的这些值。

| 名称                | 值                    | 用在哪里                                   |
| ------------------- | --------------------- | ------------------------------------------ |
| `canvas`            | `#f7f4ef`             | 页面底色                                   |
| `surface`           | `#ffffff`             | 卡片、弹框、菜单、侧边栏                   |
| `tint`              | `#f4f0fb`             | 选中的菜单项、选中的列表项、确认家庭的底色 |
| `line`              | `#ebe6dc`             | 卡片边框、分隔线                           |
| `line-strong`       | `#d9d3c7`             | 输入框和次按钮的边框                       |
| `ink`               | `#161a2b`             | 正文和标题                                 |
| `ink-soft`          | `#4b5168`             | 说明文字                                   |
| `ink-muted`         | `#6a6e7e`             | 小标签、次要信息                           |
| `primary`           | `#1d2238`             | 主按钮、成功的提示条、线条图标             |
| `violet`            | `#6d3cf0`             | 输入框获得焦点时的边框、选中标记           |
| `peach`             | `#ffe3cc`             | 欢迎横幅和主页插画背后的渐变               |
| `sun` / `sun-ink`   | `#fff1cc` / `#8a5a00` | 管理员标签、时区提示、等待同意的标签       |
| `mint` / `mint-ink` | `#dff7ea` / `#16794a` | 已同意的标签                               |
| `rose` / `rose-ink` | `#ffe4e8` / `#c0213f` | 出错、危险操作的按钮、已拒绝的标签         |
| `badge`             | `#d92d42`             | 菜单上待处理数量和未读结果的红点           |

- 页面底色上叠两团很淡的光：左上角桃色、右上角淡紫，页面滚动时不动。
- 家长的头像是名字的第一个字，底色在 `violet`、`sky`（`#2f6bff`）、`mint-ink`、`fuchsia`（`#d23be6`）、`sun-ink` 五种里按家长编号算出一种：同一位家长在哪里都是同一种颜色。孩子的头像按同样的规则：昵称的第一个字，在同样的五种颜色里按孩子编号算出一种。
- 小字和次要文字的颜色都达到无障碍要求的对比度（小字至少 4.5:1），所以 `ink-muted` 和 `badge` 取的是够深的值。

## 字体和尺寸

- 全部用系统字体：苹方、微软雅黑、思源黑体等，不带字体文件。
- 标题用最粗的字重；页面标题 30px，卡片标题 18–20px，正文 16px，小字 14px，标签 12px。
- 家庭码用等宽字体，字间距加宽。
- 可点的元素至少 44×44px；只有图标的按钮带着读屏用的名称。

## 布局

| 屏幕宽度    | 导航                                                                                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1024px 起   | 左侧 256px 宽的侧边栏：logo 图形；家庭切换按钮；当前家庭的首页、孩子、家庭管理、新成员；一条分隔线；以头像和名字为标题的一组：加入家庭、个人设置。内容区上方不再放头像 |
| 1024px 以下 | 顶栏：logo 图形、家庭切换按钮、头像；点头像弹出以头像和名字为标题的菜单：加入家庭、个人设置。底部的标签栏是首页、孩子、家庭管理、新成员                                |

- 导航按屏幕宽度分，因为侧边栏要占地方；弹框、菜单和编辑的方式按手指版和鼠标版分，见下一节。
- 当前家庭的菜单项：首页、孩子、家庭管理，每位家长都有；当前家庭的管理员还有「新成员」，有待处理的申请时显示红点和数量。
- 家长自己的一组：标题（头像和名字）不能点；「加入家庭」有未读的申请结果时带一个红点，手机和平板顶栏的头像也带。
- 没登录的页面（产品主页、孩子登录、扫码登录）顶部只有完整 logo；孩子首页是浅色的顶栏，左边是完整 logo，右边是孩子的头像和昵称、「退出」；还没有家庭的页面（开始页、没有家庭时的个人设置）顶部是完整 logo 和头像（电脑上带名字），点头像弹出同样的菜单，没有当前家庭的菜单项。
- 内容区最宽 768px（孩子、家庭管理、新成员、加入家庭、个人设置）或 1024px（首页、孩子首页），居中。
- 卡片圆角 20px，弹框和浮动面板圆角 28px，按钮是全圆角的胶囊。

## 手指版和鼠标版

按浏览器报告的主要输入设备区分：主要是触屏的（CSS 的 `pointer: coarse`）用手指版，其余用鼠标版。带触屏的笔记本主要用触控板，算鼠标版；平板接了触控板、浏览器报告成鼠标时，也用鼠标版。

|                    | 手指版                                                             | 鼠标版                                           |
| ------------------ | ------------------------------------------------------------------ | ------------------------------------------------ |
| 弹框               | 从底部升起的浮动面板                                               | 在屏幕中间                                       |
| 菜单               | 从底部升起的浮动面板                                               | 从按钮处向下展开                                 |
| 改名字、改家庭名称 | 浮动面板：标题「改名字」或「改家庭名称」、输入框、「取消」「保存」 | 原地改：输入框和「取消」「保存」出现在原来的位置 |
| 改时区             | 原地改，时区列表从底部升起                                         | 原地改，时区列表在屏幕中间                       |
| 图标按钮的说明     | 没有，只有读屏名称                                                 | 鼠标停留或键盘聚焦时显示                         |
| 悬停变色           | 没有                                                               | 有                                               |

- 浮动面板：手机上离屏幕两边和下边各 12px；更宽的屏幕上最宽 560px，在底部居中，离下边 16px；系统留了底部安全距离（比如 iPhone 的横条）时再加上。四个角都是圆的。
- 成员的操作面板顶上显示这位家长的头像和名字；孩子的操作面板顶上显示这个孩子的头像和昵称。
- 面板里再打开面板（比如手指版创建家庭时打开时区列表）：第二层面板叠在第一层上面，第一层变暗；关掉第二层回到第一层。
- 面板和弹框里的按钮：640px 以下「保存」在上、「取消」在下，都铺满；640px 起靠右排成一行。
- 截图里手机和平板是手指版，电脑是鼠标版。

## Logo

- **完整 logo**：一颗扁平风格的地球（蓝色海洋、绿色陆地、白云），一条浅蓝色轨道和一颗黄色小月亮，「好奇星球」四个字沿轨道向右上斜着排。字只占 logo 高度的约五分之一，所以完整 logo 只用在显示得大的地方：产品主页顶部 72px 高，开始页顶部 64px 高。
- **logo 图形**：同一颗地球和轨道，不带字。用在侧边栏（48px 高）、手机和平板的顶栏（38px 高），以后也用作应用图标。
- 两种都带读屏用的名称“好奇星球”。现在没有深色底的版本。

## 动画

动效参照 Fluent 2 的数值：进场的东西减速停到位，离场的东西加速离开，在两处之间移动的东西两头缓；离场比进场快。

| 曲线 | 值                               | 用途             |
| ---- | -------------------------------- | ---------------- |
| 进场 | `cubic-bezier(0.1, 0.9, 0.2, 1)` | 出现、升起、展开 |
| 离场 | `cubic-bezier(0.8, 0, 0.78, 1)`  | 消失、收起       |
| 移动 | `cubic-bezier(0.33, 0, 0.67, 1)` | 抖动、浮动、按下 |

| 动画           | 怎么动                                                                                                          | 关键帧截图                                                                                                 |
| -------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 页面打开       | 页面里的卡片从下方 12px、透明处升起，每张 250ms，依次相隔 40ms                                                  | `home-signed-in-entering`（0、120、300、620ms）                                                            |
| logo           | 从往后转 60°、缩到 80%、透明处转到位，500ms                                                                     | 同上                                                                                                       |
| 产品主页的小兔 | 从下方 40px、透明处升起，500ms；350ms 时气泡从 85% 放大弹出，250ms；之后小兔一直上下浮动 4px，每 2.4 秒一次     | `home-visitor-entering`（0、150、350、600ms）                                                              |
| 首页横幅的小兔 | 比横幅晚 120ms，从下方 40px 升起，500ms                                                                         | `home-signed-in-entering`                                                                                  |
| 弹框           | 遮罩 200ms 淡入；手指版面板从屏幕下方升到浮动的位置，300ms；鼠标版从 96% 放大到位，250ms；关闭时 150ms 反向退出 | `family-create-opening`（0、100、300ms）                                                                   |
| 菜单           | 鼠标版从按钮处向下 8px、98% 展开，150ms；手指版遮罩淡入、面板从屏幕下方升到浮动的位置，300ms                    | `menu-family-opening`（0、100、300ms）                                                                     |
| 提示条         | 从顶部上方 16px 滑下，250ms；成功的停 3 秒，出错的停 5 秒，也可以点 × 提前关掉；然后向上 8px 滑走并淡出，150ms  | `family-saved`（0、125、250、1500、3325、3400ms）；`toast-action-error`（0、125、250、2500、5250、5400ms） |
| 输错           | 输入框或家庭码的 6 个格子左右抖 6px，300ms；错误说明 200ms 淡入                                                 | 只截结束后的样子                                                                                           |
| 原地编辑       | 鼠标版名称、时区的输入框和按钮 200ms 淡入；手指版改名称的面板用弹框的动画                                       | 只截结束后的样子                                                                                           |
| 时区提示       | 从下方 12px 升起，250ms                                                                                         | 只截结束后的样子                                                                                           |
| 处理申请       | 同意或拒绝后，这一行向右滑出并收起高度，250ms；菜单上的数量放大到 120% 再回到原样，200ms                        | 只截结束后的样子                                                                                           |
| 按钮           | 鼠标版悬停时颜色 100ms 变化；两版按下时都缩到 97%，100ms                                                        | 不截                                                                                                       |

- 二维码弹框和其他弹框用同一个动画；孩子页的弹框、菜单、确认框和提示条也用上面的动画。
- 撤销一台记住的设备时，这一行和处理申请一样向右滑出并收起高度，250ms。
- 登录二维码换成对勾时没有动画，直接换。
- 孩子首页的欢迎横幅没有进场动画，横幅里的小兔老师也不单独升起。
- 关键帧截图在测试里用把动画停在某一毫秒的办法对比；其余动画只截结束后的样子。
- 系统打开“减少动态效果”时，所有动画和过渡在 100ms 内完成，不重复，小兔不再浮动。
