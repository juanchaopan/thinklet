# 视觉和动效

界面的整体感觉：暖色的米白底、白色圆角卡片、深藏青的胶囊按钮，干净、留白多。家长用的页面以小图标点缀，不放卡通人物；小兔老师只出现在产品主页、书库的欢迎横幅和孩子会看到的页面上。

## 颜色

颜色只用 Tailwind 主题里定义的这些值。

| 名称                | 值                    | 用在哪里                                                       |
| ------------------- | --------------------- | -------------------------------------------------------------- |
| `canvas`            | `#f7f4ef`             | 页面底色                                                       |
| `surface`           | `#ffffff`             | 卡片、弹框、菜单、侧边栏                                       |
| `tint`              | `#f4f0fb`             | 选中的菜单项、选中的列表项和筛选格子、确认家庭的底色、默认封面 |
| `line`              | `#ebe6dc`             | 卡片边框、分隔线                                               |
| `line-strong`       | `#d9d3c7`             | 输入框和次按钮的边框、「谁能读」的虚线圆圈                     |
| `ink`               | `#161a2b`             | 正文和标题                                                     |
| `ink-soft`          | `#4b5168`             | 说明文字                                                       |
| `ink-muted`         | `#6a6e7e`             | 小标签、次要信息                                               |
| `primary`           | `#1d2238`             | 主按钮、成功的提示条、线条图标                                 |
| `violet`            | `#6d3cf0`             | 输入框获得焦点时的边框、选中标记和对勾                         |
| `peach`             | `#ffe3cc`             | 欢迎横幅和主页插画背后的渐变                                   |
| `sun` / `sun-ink`   | `#fff1cc` / `#8a5a00` | 管理员标签、时区提示、等待同意的标签、书已下架的提示           |
| `mint` / `mint-ink` | `#dff7ea` / `#16794a` | 已同意的标签、书本页的“已获取”                                 |
| `rose` / `rose-ink` | `#ffe4e8` / `#c0213f` | 出错、危险操作的按钮、已拒绝的标签                             |
| `badge`             | `#d92d42`             | 待处理数量、未读结果的红点、孩子新书的数量和“新”               |

- 页面底色上叠两团很淡的光：左上角桃色、右上角淡紫，页面滚动时不动。
- 家长的头像是名字的第一个字，底色在 `violet`、`sky`（`#2f6bff`）、`mint-ink`、`fuchsia`（`#d23be6`）、`sun-ink` 五种里按家长编号算出一种：同一位家长在哪里都是同一种颜色。孩子的头像按同样的规则：昵称的第一个字，在同样的五种颜色里按孩子编号算出一种。
- 小字和次要文字的颜色都达到无障碍要求的对比度（小字至少 4.5:1），所以 `ink-muted` 和 `badge` 取的是够深的值。

## 字体和尺寸

- 全部用系统字体：苹方、微软雅黑、思源黑体等，不带字体文件。
- 标题用最粗的字重；页面标题 30px，书本页的书名 640px 以下 36px、640px 起 48px，卡片标题 18–20px，书的卡片上的书名 16px，正文 16px，小字 14px，标签 12px。
- 家庭码用等宽字体，字间距加宽。
- 可点的元素至少 44×44px；只有图标的按钮带着读屏用的名称。

## 布局

| 屏幕宽度    | 导航                                                                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1024px 起   | 左侧 256px 宽的侧边栏：logo 图形；家庭切换按钮；当前家庭的书库、孩子、家庭管理；一条分隔线；以头像和名字为标题的一组：加入家庭、个人设置。内容区上方不再放头像 |
| 1024px 以下 | 顶栏：logo 图形、家庭切换按钮、头像；点头像弹出以头像和名字为标题的菜单：加入家庭、个人设置。底部的标签栏是书库、孩子、家庭管理                                |

- 1024px 以下，顶栏吸在屏幕顶上，底色是半透明的 `surface` 带模糊；底部的标签栏固定在屏幕底部，再加上系统留的底部安全距离（比如 iPhone 的横条），内容下面留出标签栏的高度。整页截图里标签栏在页面最下面。
- 导航按屏幕宽度分，因为侧边栏要占地方；弹框、菜单和编辑的方式按手指版和鼠标版分，见下一节。
- 当前家庭的菜单项：书库、孩子、家庭管理，每位家长都有。
- 红底数字：白字，圆形，一位数时 20px，两位数以上变宽成胶囊。家庭切换按钮上是自己当管理员的全部家庭的等待中的申请数，家庭切换菜单里每个家庭后面是它自己的数，「家庭管理」（侧边栏和标签栏）上是当前家庭的数；没有时不显示。
- 家长自己的一组：标题（头像和名字）不能点；「加入家庭」有未读的申请结果时带一个红点，手机和平板顶栏的头像也带。
- 没登录的页面（产品主页、孩子登录、扫码登录）顶部只有完整 logo；孩子首页和孩子的个人设置是浅色的顶栏，左边是完整 logo，右边是孩子的头像（1024px 起头像右边带昵称），点了进入孩子的个人设置，在个人设置页上它标成当前页（`tint` 底）；还没有家庭的页面（开始页、没有家庭时的个人设置）顶部是完整 logo 和头像（电脑上带名字），点头像弹出同样的菜单，没有当前家庭的菜单项。
- 内容区最宽 768px（孩子、家庭管理、加入家庭、个人设置）或 1024px（书库、书本页、孩子首页），居中。
- 卡片圆角 20px，弹框和浮动面板圆角 28px，按钮是全圆角的胶囊。
- 危险的操作放在页面最下面：一条细线下面靠右，`rose-ink` 的文字按钮，比如个人设置页的「删除账号」，家庭管理页的「删除家庭」（和「离开家庭」在同一行，排在最后）。
- 现在做不了的按钮（管理员的「离开家庭」和「删除账号」）变淡（`ink-soft`，40% 不透明度）、点不了，前面一行 `ink-muted` 的小字说明原因；手机上放不下时，说明在按钮上面一行，都靠右。

## 书

- **欢迎横幅**：书库的横幅比孩子首页的矮，小兔老师（半身挥手）也小一号。
- **筛选**：三个白色胶囊按钮排成一行，“年级：全部 ▾”“学科：全部 ▾”和范围；筛选了的按钮是 `tint` 底。手机上放不下时折到第二行。年级的菜单是三列的格子，学科的是两列，每个格子圆角带边框，选中的是 `tint` 底、里面有 `violet` 的对勾；底下是「清除」「完成」。范围的菜单是一列，书库前面是小木屋、我家的书前面是心形小房子的插画，孩子前面是小头像，选中的一项 `tint` 底、行尾有对勾。
- **书的卡片**：白色卡片，顶上是 3:4 的封面，下面是书名、“一年级 · 数学”（小字）、两行简介（小字）和底部一行。底部一行：没获取时是「获取」（主按钮，小号）；获取了是 `mint-ink` 的“✓ 已获取”，右边是在读的孩子的头像（24px，互相叠一点，手机上小一号，最多 3 个，多的写“+2”），没有孩子在读时是 32px 的虚线圆圈，里面一个「+」。
- **封面上的标签**：“已下架”是左上角的白色小胶囊；孩子首页的“新”是右上角的 `badge` 小胶囊；「…」是右上角的白色圆形按钮。
- **默认封面**：`tint` 底，中间是线条的书本图标。
- **书本页**：顶上是铺满内容区宽度的色带，背后是这本书的封面图放大、模糊、调淡，往下慢慢淡进页面底色；没有封面的书用 `tint`。封面画成一本书：书脊那一侧有一条暗一点的边和细折痕，书脊那边的圆角小、开口那边的圆角大，下面有一团柔和的阴影。平板和电脑上封面在左、书名和操作在右，和封面底边对齐；手机上全部居中，封面在上。年级和学科是书名上面的两个白色小胶囊。已获取是 `mint` 底的小胶囊；「谁能读」是白色胶囊按钮，里面是孩子的头像、“小米、豆豆可以读”和向下的箭头，没有孩子在读时是虚线「+」和“选择谁能读”。色带下面是“这本书讲什么”小标题和大一号的简介正文。「从我家的书里移除」是 `rose-ink` 的文字按钮，在简介下面一条细线下方，靠右。下架的提示是色带里 `sun` 底的一条。
- **「谁能读」弹框**：每个孩子一行，至少 56px 高，整行能点；在读的孩子这一行 `tint` 底，行尾 `violet` 的对勾；点不了的行变淡。

## 手指版和鼠标版

按浏览器报告的主要输入设备区分：主要是触屏的（CSS 的 `pointer: coarse`）用手指版，其余用鼠标版。带触屏的笔记本主要用触控板，算鼠标版；平板接了触控板、浏览器报告成鼠标时，也用鼠标版。

|                    | 手指版                                                             | 鼠标版                                           |
| ------------------ | ------------------------------------------------------------------ | ------------------------------------------------ |
| 弹框               | 从底部升起的浮动面板                                               | 在屏幕中间                                       |
| 菜单               | 从底部升起的浮动面板                                               | 从按钮处向下展开                                 |
| 改名字、改家庭名称 | 浮动面板：标题「改名字」或「改家庭名称」、输入框、「取消」「保存」 | 原地改：输入框和「取消」「保存」出现在原来的位置 |
| 改时区             | 原地改，时区列表从底部升起                                         | 原地改，时区列表在屏幕中间                       |
| 加载更多的书       | 滑到底自动加载                                                     | 「加载更多」按钮                                 |
| 图标按钮的说明     | 没有，只有读屏名称                                                 | 鼠标停留或键盘聚焦时显示                         |
| 悬停变色           | 没有                                                               | 有                                               |

- 浮动面板：手机上离屏幕两边和下边各 12px；更宽的屏幕上最宽 560px，在底部居中，离下边 16px；系统留了底部安全距离（比如 iPhone 的横条）时再加上。四个角都是圆的。
- 成员的操作面板顶上显示这位家长的头像和名字；孩子的操作面板顶上显示这个孩子的头像和昵称；书的操作面板顶上显示这本书的小封面和书名。
- 面板里再打开面板（比如手指版创建家庭时打开时区列表）：第二层面板叠在第一层上面，第一层变暗；关掉第二层回到第一层。
- 面板和弹框里的按钮：640px 以下「保存」在上、「取消」在下，都铺满；640px 起靠右排成一行。
- 截图里手机和平板是手指版，电脑是鼠标版。

## Logo

- **完整 logo**：一颗扁平风格的地球（蓝色海洋、绿色陆地、白云），一条浅蓝色轨道和一颗黄色小月亮，「好奇星球」四个字沿轨道向右上斜着排。字只占 logo 高度的约五分之一，所以完整 logo 只用在显示得大的地方：产品主页顶部 72px 高，开始页顶部 64px 高。
- **logo 图形**：同一颗地球和轨道，不带字。用在侧边栏（48px 高）、手机和平板的顶栏（38px 高），以后也用作应用图标。
- 两种都带读屏用的名称“好奇星球”。现在没有深色底的版本。

## 动画

动效参照 Fluent 2 的数值：进场的东西减速停到位，离场的东西加速离开，在两处之间移动的东西两头缓；离场比进场快。

| 曲线 | 值                               | 用途             |
| ---- | -------------------------------- | ---------------- |
| 进场 | `cubic-bezier(0.1, 0.9, 0.2, 1)` | 出现、升起、展开 |
| 离场 | `cubic-bezier(0.8, 0, 0.78, 1)`  | 消失、收起       |
| 移动 | `cubic-bezier(0.33, 0, 0.67, 1)` | 抖动、浮动、按下 |
