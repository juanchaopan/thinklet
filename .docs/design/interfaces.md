# 后端接口

所有接口都在 `/api` 下。请求和响应的格式定义在 `packages/contracts` 的 Zod schema 里。

## GET /api/health

健康检查，不需要登录，只读，不改任何数据。冒烟测试经过前端的 `/api` 转发调用它。

### 检查项

| 检查项     | 怎么检查                  | 超时 |
| ---------- | ------------------------- | ---- |
| `database` | 在数据库上执行 `SELECT 1` | 5 秒 |
| `storage`  | 确认配置里的存储桶能访问  | 5 秒 |

两项同时检查。超过 5 秒没有结果的，算作失败；这段时间也够 Neon 数据库从暂停里唤醒。

### 响应

全部正常时返回 `200`：

```json
{
  "status": "ok",
  "checks": {
    "database": "ok",
    "storage": "ok"
  }
}
```

有任何一项失败就返回 `503`，失败的那一项标成 `"error"`：

```json
{
  "status": "error",
  "checks": {
    "database": "ok",
    "storage": "error"
  }
}
```

- 响应里不带错误详情，免得泄露内部信息。
- 失败的原因写进日志，包括超时和错误信息，但不写连接地址和凭据。
