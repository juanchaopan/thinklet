# 好奇星球 设计

设计由这里的文字和 `screens/` 里确认过的截图组成。原型源码放在各 issue 的 scratch 分支上，不放在 `main`。

| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `look.md`       | 视觉和动效：颜色、字体、布局、书的卡片和书本页、手指版和鼠标版、图标和插画、logo、动画                                                                               |

## 界面

截图按 `screens/<状态>--<尺寸>.png` 命名，每个状态有手机（390×844）、平板（820×1180）、电脑（1440×900）三张；手机和平板按手指版画，电脑按鼠标版画（见 `look.md`）。弹框、菜单和提示条打开时的状态只截一屏高，其余截整页；整页的截图里，手机和平板底部的标签栏在页面最下面。动画的关键帧另按 `screens/<动画>--<尺寸>--<毫秒>ms.png` 命名，见 `look.md` 的“动画”一节；只在某一刻看得到的提示条（`toast-offline`、`toast-copied`）也按这个方式命名。

每个页面的浏览器标题是“<页面名> - 好奇星球”，产品主页、书库和孩子首页只写“好奇星球”；书本页的页面名是书名。

## 原型源码和插画

- 原型源码在 scratch 分支 `scratch/9-library` 的 `prototypes/9-library/`：手写 HTML 加 Tailwind，`render.mjs` 按三种尺寸截图（手机和平板模拟触屏，整页截图先把屏幕拉到页面的高度），`strip.mjs` 把关键帧拼成一张图，`contact.mjs` 把一个状态的三种尺寸拼成一张图；二维码用 `qrcode` 生成。书库在 `src/pages-library.mjs`，书本页在 `src/pages-book.mjs`，书的卡片、封面和「谁能读」弹框在 `src/books.mjs`，示例书在 `src/sample-books.mjs`；孩子页在 `src/pages-children.mjs`，孩子登录、扫码登录和孩子首页在 `src/pages-child.mjs`。
- 示例书的封面由 `covers.mjs` 生成，每本一张纯色的 600×800 PNG，放在 `covers/<书本编号>/cover.png`；实现时复制到仓库的 `content/books/`。
- 插画和图标都在同一目录的 `art/` 里。小兔老师的全身图 `rabbit.webp` 来自参考项目；其余由 OpenAI Images API（`gpt-image-2.5-sunburst`）生成，每张的提示词写在 `src/art-list.mjs`，生成脚本是 `generate.mjs`。线条图标（复制、分享、二维码、显示密码、设备、书本）是 `src/ui.mjs` 里手写的 SVG。实现时把用到的文件复制进前端的静态资源。
