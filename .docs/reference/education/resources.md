## 对 thinklet 的意义

- 部署平台（Vercel、Neon）thinklet 已经自己定了（0007），POC 的实际配置对 thinklet 用处不大。POC 的教训在于用法：部署保护不要为了冒烟关掉；不要依赖 GitHub 的定时任务；环境的密钥放在环境里，限制分支。
- 外部账号（OpenAI、Gmail、edge-tts）都不适合 thinklet：生产在中国大陆，要遵守个人信息保护的规定，也要有明确的条款。以后做 AI、邮件或语音时，从能在大陆合规使用的服务里选。
- POC 遗留的资源（spike 的工作流和两个 OpenAI 密钥、Supabase 的旧项目、Vercel 的旧探针项目）是否清理，是 POC 自己的事，这次分析没有动它们。
