# POC 用到的外部资源

POC 用到的每个外部资源，都从仓库、CI 的配置和运行记录里推断出来。不登录就能查的都查了：GitHub 仓库的设置和记录，以及线上的测试环境（只发 GET 请求，不注册账号、不改数据）。需要登录的部署平台和外部账号，按用户的决定没有登录，只按仓库推断记录。只记录密钥的名称，没有读取或记录任何密钥的值。

## GitHub

- **仓库**：代码、issue、PR、Actions、分支规则。查了仓库设置；`main` 的经典分支保护（必过检查是 CI 汇总、提交信息检查、风险关卡；要求分支最新；管理员可以绕过；不要求评论处理完；不要求 review；允许 merge commit 和 rebase）；没有 ruleset；`staging` 环境没有保护规则和环境级的密钥；12 个仓库密钥和 13 个变量的名称；全部运行记录、PR、issue、标签、artifact。没查：装了哪些 GitHub App、webhook，要所有者在网页上看或更高权限的令牌。
- **Actions 的 artifact**：每天的加密备份。13 份，每份约 72 KB，各保留 14 天，缺两天的备份；公开仓库里任何登录的用户都能下载这些加密文件。解密要私钥，不应该取得。
- **issue 作为通知渠道**：19 个告警 issue，全部已关闭；3 个依赖漏洞 issue 开着（都是开发依赖）。
- **安全功能**：密钥扫描和推送保护开着；Dependabot 告警和安全更新关着；没有 CodeQL。
- **依赖更新**：Dependabot 开过 7 个 PR，有一个开着、截图测试失败；Renovate 的 GitHub App 在最后一天刚装，配置 PR 开着、CI 失败。Renovate 的安装范围没查。
- **Claude 的 GitHub App 和订阅**：给 CI 里的 AI 评审和 `@claude` 用；三个工作流从没真正运行。App 装没装没查。
- **托管的 runner**：所有 CI、发布、备份、告警探测都跑在 `ubuntu-latest` 上；定时任务严重延迟和丢失（见 [delivery.md](delivery.md)）。

## 托管和数据库

- **Vercel（一个团队、一个 staging 项目）**：测试环境的前端静态文件和后端函数，用 REST API 和一个部署令牌发布，团队和项目的 id 写死在工作流里。从仓库知道：免费版、新加坡区域、Node 24、部署保护关着，另有一个早期 spike 留下的探针项目。线上测试环境（GET）：首页、健康检查都正常，运行的是 `main` 的最新提交；响应头里只有 HSTS 和缓存头，没有 CSP 等安全响应头，HTML 还带着 `Access-Control-Allow-Origin: *`；首屏有一段设主题的内联脚本。没查：项目设置、环境变量名、域名配置、遗留的候选部署、运行日志。
- **staging 的自定义子域名**：DNS 托管在一个第三方的域名服务上，公开的 DNS 记录是 CNAME 指向 Vercel；名字是托管 spike 时起的，一直沿用。没查：域名账号里的记录、子域归属和续期。
- **Neon（每个环境两个项目）**：测试环境的应用库和删除清单库，用两个连接串密钥和一个主机名变量连接。从备份的运行日志知道是 PostgreSQL 18、新加坡；生产的两个项目还没建。没查：用量、恢复窗口、分支（Neon 没有只读的 API 密钥）。
- **Supabase 的旧项目**：以前的测试环境数据库，已经不再连接。没查：是否还在、里面是否还有合成账号。

## 外部服务和账号

- **Gmail 发件账号**：家长的验证邮件和找回密码邮件，用 SMTP 和应用专用密码。只知道变量和密钥的名称；POC 对 Gmail 条款的核对，靠的是维护者复制下来的帮助页面正文。没查账号本身。
- **126.com 收件箱**：维护者的测试收件邮箱，人工使用，里面可能有测试家长的邮件。没查。
- **OpenAI API**：AI 解题提示（GPT-6 Luna）和语音转写，以及 spike 的基准测试。staging 一个密钥，仓库级另有两个给 spike 的工作流用；资格开关和月度预算是变量；测试环境上两项资格开关都开着。没查：用量、项目、密钥是否还在用。
- **OpenAI Codex 和它的图像生成**：12 个 `codex/` 分支的开发，课堂的背景图和角色图。只从分支名、容器配置和图库的元数据推断。
- **微软 Edge 的在线朗读（edge-tts）**：制作时生成课程的旁白 mp3，提交进仓库；用固定版本的 Python 包跑，不需要账号。它调用没有公开的接口，没有开发者条款；能不能用来发布给孩子的音频，POC 自己也没确认。
- **容器镜像和包源**：Docker Hub 的 PostgreSQL、Node、nginx 镜像，微软的 Playwright 镜像，PostgreSQL 官方的 apt 源，npm，PyPI。镜像用标签，没有按摘要固定。

## 遗留

spike 的工作流和两个 OpenAI 密钥、Supabase 的旧项目、Vercel 的旧探针项目都还在。是否清理是 POC 自己的事，这次分析没有动它们。
