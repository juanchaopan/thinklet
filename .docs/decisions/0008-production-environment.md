# 0008 生产环境

## 背景

用户以中国大陆为主，服务器要放在中国大陆，网站要做 ICP 备案。生产环境的建立和部署，以及 ICP 备案，不在 #1 的范围内。

## 比较过的方案

- 现在就选定阿里云。
- 现在就选定腾讯云。
- 等做生产环境时再定。
- 现在先做一个生产部署任务的空壳。

## 决定

- 生产环境的云服务商，等做生产环境时再定。
- 在架构的“Deployment targets”里记一行 production：中国大陆的云，服务商、地址和资源都待定。
- 这次不建生产部署任务。`/deploy production` 要等建生产环境的 issue 做完才能用。

## 理由

- 这次的目标只到测试环境，现在选服务商还没有依据。
- 空壳任务启动后只会失败，将来搭生产环境时也要重写。

## 代价

- 在生产环境建好之前，没法发布给真实用户。
- 代码必须保持通用，不能依赖 Vercel 和 Neon 的专有接口（REVIEW.md 第 4 条）。

## 何时重新考虑

- 准备上线给真实用户的时候。
