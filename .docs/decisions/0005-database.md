# 0005 数据库

## 背景

数据要写入后立刻可见。以后的题目内容，不同题型的结构会各不相同。

## 比较过的方案

- PostgreSQL。
- MySQL。

## 决定

用 PostgreSQL。开发和测试用的版本与 Neon 项目的主版本一致。

## 理由

- 开源的关系型数据库，有事务，能保证写入后立刻可见。
- JSONB 适合存结构各不相同的内容，查询和索引都比 MySQL 的 JSON 灵活。
- Neon 和国内的主流云都有托管的 PostgreSQL。

## 代价

- 国内云上托管的 MySQL 更便宜，选择也更多。

## 何时重新考虑

- 生产环境选定的云上，托管 PostgreSQL 的价格或功能明显不如 MySQL。
