# 0003 前端框架和渲染方式

## 背景

前端是一套自适应网页，在手机、平板和电脑上使用，内容大多要登录后才能看到。

## 比较过的方案

- 框架：Angular；React；Vue。
- 渲染：单页应用，在浏览器里渲染；服务器端渲染（Angular SSR）。

## 决定

用 Angular（TypeScript）做单页应用，在浏览器里渲染。全部用独立组件和 signals。

## 理由

- 团队熟悉 Angular。它自带路由、表单、测试和构建工具，约定强，适合一个人配合 AI 代理长期维护。
- 单页应用构建出来只是静态文件，不占服务器的计算资源。内容要登录后才能看，搜索引擎收录的需求不大。

## 代价

- 首屏要先下载 JavaScript，比服务器端渲染稍慢。
- 公开页面以后如果要被搜索引擎收录，单页应用不够友好。

## 何时重新考虑

- 要做需要被搜索引擎收录的公开页面。
- 首屏速度成了问题。
