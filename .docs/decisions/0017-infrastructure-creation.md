# 0017 基础设施怎么建

## 背景

测试环境只有两个 Vercel 项目、一个 Neon 项目和一个存储桶。生产环境在国内云上，本来就和测试环境不同。

## 比较过的方案

- 直接用 `vercel` 和 `neonctl` 命令行创建，命令记在架构文档里。
- 用 OpenTofu 写成基础设施即代码。

## 决定

直接用 `vercel` 和 `neonctl` 命令行创建。命令记在 `architecture.md` 的“Deployment targets”一节，执行前先用 `--help` 核对参数。

## 理由

- 资源很少，不用多学一个工具，也不用找地方存状态文件。
- 测试环境和生产环境本来就不同，用代码保持两边一致的好处不大。
- Neon 的官方 Terraform provider 还是测试版。

## 代价

- 在网页控制台里做的改动不会被发现。
- 重建环境要照着命令手动再执行一遍，容易漏掉参数。

## 何时重新考虑

- 建生产环境时，资源多了，或者要频繁重建环境。
