# 0037 分批加载

## 背景

#9 的书库往下滑到底或点「加载更多」时，分批取书。书本会被导入命令增减。

## 比较过的方案

- 游标分批。
- 按页码或偏移分批。

## 决定

列表接口用游标分批：每批按固定的顺序取，顺序的最后一项是唯一的；响应带下一批的游标，也就是这批最后一项的排序位置，编码成一个不透明的字符串；没有更多时不带游标。

## 理由

- 加载中途增减了书本，也不会重复或漏掉。
- 按索引往后取，不用数过前面的行。

## 代价

- 不能直接跳到第几页。
- 后端要校验游标，格式不对时拒绝。

## 何时重新考虑

- 要显示总页数或跳页时。
