# 0015 配置

## 背景

后端从环境变量读取数据库地址、存储凭据等配置。配置错了要尽早发现。

## 比较过的方案

- `@nestjs/config` 加 Zod 校验。
- 直接读 `process.env`。

## 决定

用 `@nestjs/config` 加 Zod 校验：启动时校验全部环境变量，缺了或格式不对就拒绝启动，并说明是哪个。开发机和测试用的值写在不提交的 `.env` 文件里，示例写在提交的 `.env.example` 里。

## 理由

- 部署后立刻就能发现配置错误，不用等到某个功能用到时才报错。
- 和接口校验用同一个库。

## 代价

- 多一个库。

## 何时重新考虑

- 配置来源变多了，比如要接配置中心。
