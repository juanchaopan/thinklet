# 0006 对象存储

## 背景

书本和教学里会有图片、音频这类文件。测试环境在境外，生产环境在中国大陆，两边的对象存储产品不会一样。

## 比较过的方案

- 测试环境用 Cloudflare R2：兼容 S3，有 10 GB 免费额度，开通时要绑定付款方式。
- 测试环境用 Vercel Blob：不用再开账号，但它不是 S3 接口，生产环境要另写一套。
- 测试环境用生产那家云的对象存储（香港区域）：最接近生产环境，但现在就要有实名认证的云账号。
- 测试环境用 Neon 对象存储：兼容 S3，免费套餐每个项目有 5 GB，和数据库在同一个 Neon 项目里。

## 决定

- 代码只走 S3 接口，用 `@aws-sdk/client-s3`。
- 测试环境用 Neon 对象存储，和数据库放在同一个 Neon 项目里。
- 生产环境换成国内云的对象存储时，只改配置。

## 理由

- 用户用过 Neon 对象存储，免费额度够用，数据库和文件都在一家，账号和密钥都更少。
- 阿里云 OSS 和腾讯云 COS 都兼容 S3，生产环境换过去不用改代码。

## 代价

- 测试环境和生产环境的对象存储不是同一种产品，只有 S3 接口的公共部分是可靠的。
- 数据库和文件共用一个 Neon 项目的免费额度。

## 何时重新考虑

- 测试环境的文件超出免费额度。
- 选定生产环境的云服务商时。
