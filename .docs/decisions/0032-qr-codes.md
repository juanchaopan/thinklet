# 0032 二维码

## 背景

家庭管理页上可以显示邀请链接的二维码，对方用手机相机扫码就能打开邀请链接。#8 的孩子登录也要显示一次性登录链接的二维码。前端的 CSP 是 `img-src 'self'`，不允许 `data:` 图片地址。

## 比较过的方案

- `qrcode`：MIT 许可证，用的人最多的 JavaScript 二维码库。
- `uqr`：MIT 许可证，很小、没有依赖，用的人少一些。
- 自己写二维码编码。

## 决定

前端用 `qrcode` 取出二维码的点阵，由 Angular 组件用模板画成页面里的 SVG。不生成 `data:` 图片，也不把 HTML 字符串塞进页面。

## 理由

- 用的人多，维护的时间长。
- 画成 SVG，不用放开 CSP，也不用绕过 Angular 的安全检查。
- 二维码编码里的纠错码和掩码，自己写容易出错，不划算。

## 代价

- 前端多一个运行时依赖，要跟着升级。
- 打包体积多几十 KB。只在显示二维码的页面按需加载，可以减小。

## 何时重新考虑

- `qrcode` 停止维护，或者出了安全问题。
- 需要在后端生成二维码图片，比如发邮件时。
