# 0014 日志

## 背景

后端的日志要在 Vercel 和以后国内云的日志服务里都能查，而且不能泄露密码和孩子的个人信息。

## 比较过的方案

- pino（nestjs-pino）输出 JSON 日志。
- NestJS 自带的 Logger。

## 决定

用 nestjs-pino。每条日志是一行 JSON，自动带请求编号；密码和孩子个人信息的字段列进遮挡列表，自动遮掉。

## 理由

- 能按字段搜索。
- 能自动遮挡敏感字段，配合安全指标和 REVIEW.md 第 2 条。

## 代价

- 在开发机上直接看 JSON 不如文本好读，要用 pino-pretty 这类工具来格式化。

## 何时重新考虑

- 生产环境的日志服务要求别的格式。
